# Personal Portfolio — Responsive Website

A modern, accessible, and fully responsive personal portfolio built with
**vanilla HTML5, CSS3, and JavaScript** (no frameworks).

![Portfolio screenshot](./images/screenshot.png)

## ✨ Features

- Semantic HTML5 structure (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Mobile-first responsive design with breakpoints at **480px / 768px / 1024px**
- CSS Grid + Flexbox layouts
- **Dark mode** with system preference detection + manual toggle (persisted)
- Accessible mobile hamburger navigation (keyboard + ARIA)
- Client-side contact form validation with inline errors
- Smooth transitions and reduced-motion support
- WCAG 2.1 AA-friendly: focus-visible outlines, skip link, alt text, ARIA labels
